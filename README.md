# Mini ERP + CRM Operations Portal

A streamlined Operations Portal combining core ERP (Enterprise Resource Planning) and CRM (Customer Relationship Management) workflows into a unified full-stack application.

---

## 🚀 Tech Stack

### Frontend
- **Framework / Library**: React (JavaScript)
- **Build Tool**: Vite
- **Styling**: Tailwind CSS

### Backend
- **Runtime**: Node.js (JavaScript)
- **Framework**: Express.js
- **API Architecture**: REST APIs

### Database & ORM
- **Database**: PostgreSQL (Neon / Supabase)
- **ORM**: Prisma ORM

### Security & Validation
- **Authentication**: JWT (JSON Web Tokens) & bcrypt
- **Schema Validation**: Zod

### Deployment
- **Frontend**: Vercel
- **Backend**: Render / Railway
- **Database**: Neon / Supabase

> **Note**: This project is built entirely in **JavaScript** (no TypeScript).
